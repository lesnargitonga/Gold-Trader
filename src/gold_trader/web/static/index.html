Bridge URL configuration

Set in your shell environment before starting agent-cycle and the UI:

export GOLD_BROKER=mt5_remote
export GOLD_BRIDGE_URL=http://127.0.0.1:8765
export GOLD_BRIDGE_SECRET=<shared secret>

The UI itself runs on port 8770 to avoid colliding with the MT5 bridge on 8765.
